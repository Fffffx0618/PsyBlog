# 数值分析(85/3.9)

!!!info "课程信息"
    - 学期：2024-2025 春夏
    - 学分：2.5
    - 教师：**许威威**老师  
    - 分数构成：
        - 平时分 60% ：作业 5% + project 36% + topic 15% + quiz 4%
        - 期末 40%

> 考的很烂的一门课，期末感觉基本都翻到了，但是卷面分数很低。😭

xww老师上课风格有点ppt reader，上课偶尔会让你写一道题交上来（也就是所谓的pop quiz），这学期也点过一次名；project就是PTA 上的 8 道函数题。时间上比较宽松，但想要写全对还是得花一些心思的；topic就是给你一个题目，然后以小组为单位进行一个pre，总体还是比较轻松的。

个人感觉如果你把它作为一门数学课去学，希望理解数学推导的过程，这门课还是挺难的。当时如果你从使用工具的角度来看，学起来就没那么累了。而且期末考主要考察你会不会用这些方法，而不是让你去推导这些公式。

期末考试难度和往年差不多，题型就是选择、判断、解答。个人感觉，题目能不能写出来主要取决于能否在书上翻到对应的题目。想我就有一道选择两道填空没翻到（悲），大题建议多做几张历年卷，感觉考得都大差不差。此外建议把作业答案和笔记都打印下来，因为期末考是开卷的，可以显著提高答题效率。
