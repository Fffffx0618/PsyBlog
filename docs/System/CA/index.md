### 理论课
体系结构的前半个学期是hsb老师上的（hsb老师的最后一节课还有本学期唯一一次点名，不过是来了的加分），后半个学期是wxh老师上的。hsb老师给人一种ppt reader的感觉，wxh老师上课就比较有激情，讲的也很详细。体系结构前半个学期基本都在讲计组的内容，在原有cache的基础上讲了各种优化方式，以及浮点数流水线。后半个学期主要讲Data Parallelism和Thread Parallelism，这部分内容还是挺不一样的。


### 实验课
体系实验的难度相较于计组有了明显下降，六个实验都是直接给出代码框架让你填空。而且体系的实验是两人一组完成的，这更是直接让工作量减半。唯一比较麻烦的是我们班每次实验报告都要求画出原理图（五级流水线、cache等结构），每次画图都要画很久。


### 期末
众所周知，体系结构的期末考试范围是所有老师的并集，因此在复习的时候常常需要**预习**新内容，比较建议的是面向**cr老师**的ppt复习，因为cr老师讲的内容比较详细、基本覆盖了期末考试的内容。时间来不及的话也可以先看24-25朋辈辅学课件，以及cr老师和bk老师的复习课ppt，从中检查是否有自己老师没有讲的地方。（比如hsb/wxh班就没有讲Synchronization、流水线的部分内容以及一些细枝末节的东西）

关于A4，今年体系结构的考试难度不大，涉及的范围比较广，主要考察我们的**英语阅读理解能力**以及**对课程整体的把握能力**。除此之外，CA的题型好像一直在变化，今年是<u>30道选择（60分）+4道大题</u>，去年是<u>15道选择（30分）+5道大题</u>，可见题型每年都在变动。
