### 实验课

* 实验课由两位助教共同负责。前几次实验主要是熟悉实验设备以及简单的电路连接。这部分按 PPT 步骤操作即可，相对较为简单。
* 后续试验主要是**编写代码->生成bit流->上板验收**，可以用实验室电脑里的ISE，也能在自己电脑里安装Vivado，个人推荐后者。前几个实验会用 Logisim 绘制电路图，并将其转换为 Verilog 代码；但到了后期就要求使用 Verilog 进行开发。Verilog 需要自学的语言，语法期末会有几道填空，难度并不高，语法可以参考“菜鸟教程”。
* 个人感觉实验课的体验不是很好，因为PPT都是关于ISE的，而很多人（包括我）用的是Vivado。个人认为PPT讲的不是很具体，并且和瓜豪的文档存在一定区别，也不能完全参考瓜豪的实验文档。总之做实验很多时候都是仰仗前人的宝贵财产。

### 大程

- 大程要求设计一个能在 SWORD 板上运行的小游戏，可以一个人做，也能三人组队，拓展要求（实际上大家都做了）为使用PS2接口的键盘等外接设备。大程开始时间一般在**期末周开始前一两周**，**期末考结束一段时间**后截止。刚开始做的时候完全不会（~~虽然做完也是啥也不会~~），除了 Verilog 语法外，还得了解 VGA 、IP核等内容。但还好有前人撰写的详细资料，不然在期末周我是完全作不出大程的。生成bit流更是不得不品的一环，Vivado你是真的慢啊......

#### 期末

* 面向历年卷复习，虽然你可能上课没怎么听懂，知识学得也不是很好，但多做几张理念卷你就会发现题型其实比较固定，虽然今年考了好几个我完全没复习的知识点（悲）。
* 题型有填空、选择、化简题、设计题等，今年最后一题不难，但挺费时间的，那个电路图花了好久。
